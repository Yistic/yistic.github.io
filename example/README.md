# low — example site

A complete demo site using the `low` theme. Nothing here is real; replace it
with your own content.

## Running

    bundle install
    bundle exec jekyll serve

Then open http://127.0.0.1:4000

## What it demonstrates

- `index.md` — the home layout, with an identity paragraph and a projects list
- `_posts/` — two tagged posts sharing a tag, so "Related Articles" renders
- `archive.md` — posts grouped by year
- `tags.md` — tag index; individual tag pages are generated by `_plugins/tag_generator.rb`
- `about.md` — a standard page, picked up automatically by the header nav

## Configuration notes

`title` and `tagline` are separate on purpose. `jekyll-seo-tag` joins them for
the homepage `<title>`, so do not repeat your name inside `tagline` — that
produces "Jane Doe | Jane Doe — Notes" and reads as keyword stuffing.

Any root-level `.md` file with a `title` in its front matter is added to the
header navigation automatically.
