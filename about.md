# About

Jane Doe. Systems programmer, based somewhere with bad weather and good coffee.

I have spent about a decade writing C in places where the abstraction had
already been stripped away — kernel drivers, embedded firmware, and a long
detour through emulator internals. I write here because explaining a bug
properly is the only reliable way to find out whether I understood it.

Nothing on this site is a tutorial rewritten from documentation. If a post
describes a failure mode, I hit that failure mode.
